# 图片加密

图片混淆 + 隐写水印双模式合一的本地图片加密工具：一个程序两种保护——**图片混淆**把图片从像素层打成乱码（可还原的视觉加密），**隐写水印**把文字/图片水印藏进图片（不可见的所有权标记）。全程本地处理，不联网不上传。

## 功能

### 乱序混淆模式
- 三种加密方式：吉尔伯特曲线-GC / 快速混淆-RO / 分块大小-BS（块大小 1~4096 自由设定），可叠加色彩反转 CI
- **命名参数编码**：输出名 `序号-方式[-分块w×h][-密钥][-CI]`，解密所需信息随文件携带
- **解密自动提取**：点「解密」自动从文件名识别方式/分块/密钥/CI，无需手动选择；兼容旧命名
- 序号按输出目录已有文件自动续排；批量带进度条；单张连续加解密
- 输出自动进入默认输出文件夹的「乱序混淆」子目录（单张弹保存框默认定位、批量直接输出）
- 算法与 13123123.xyz 逐字节兼容（61 组交叉验证）

### 隐写水印模式
- 文字/图片水印嵌入（双密码自然数），批量、拖入、容量预检
- 批量提取三种模式：文字（字符串）/ 位图（0/1 数组）/ 图片（保存到源文件旁）
- 提取参数留空按文件名 `序号-img-wm-bits` 自动识别；识别失败提示手动输入
- 输出防覆盖命名，自动进入默认输出文件夹的「隐写水印」子目录
- 算法基于 blind_watermark（MIT），已融合为项目内单文件 `wm_core.py`

### 全局设置（顶栏右上角 ⚙）
- 唯一设置项：**默认输出文件夹**——确定后自动创建「乱序混淆」「隐写水印」两个子文件夹，两种模式的输出默认保存到对应子文件夹；QSettings 持久化

## 使用

1. 双击安装（或运行安装目录的 `ImageEncryption.exe`）
2. 左栏导入图片（选择图片/拖入/移除/清空——两模式共用，切模式文件保留）
3. 顶栏切换模式：**乱序混淆** / **隐写水印**，右栏配置参数后点主按钮
4. 首次使用点右上角 ⚙ 设置默认输出文件夹（自动创建「乱序混淆」「隐写水印」两个子文件夹）

## 重建发布物

```bat
# onedir 主程序（PyInstaller）
py -m PyInstaller --noconfirm --clean ImageEncryption.spec

# 安装包（Inno Setup 6）
ISCC.exe installer.iss   # 产出 测试\图片加密\图片加密_2.0.0.exe
```
